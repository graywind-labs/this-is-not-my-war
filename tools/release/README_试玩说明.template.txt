《这不是我的战争》Windows 试玩版

启动方法
========

1. 请先完整解压整个目录，不要只复制单个 EXE。
2. 双击根目录的“启动游戏.exe”。
3. 启动器会自动启动本机 AI 后端，确认服务就绪后再进入游戏。
4. 点击窗口右上角 X、主菜单“退出游戏”或游戏内“退出到桌面”后，启动器会自动关闭本次启动的后端进程并自行退出。

运行要求
========

- Windows 10 / 11 64 位系统。
- 需要联网使用 DeepSeek 文本 AI 和百炼语音识别。
- 不需要安装 Godot、Python、VSCode 或其他开发工具。
- 首次运行时 Windows SmartScreen 或安全软件可能提示未签名程序，请确认文件来自可信来源。

AI 服务
-------

- 默认“试玩服务”使用随本包配置的 DeepSeek 文本模型。
- 对话框中的语音输入使用百炼 qwen3-asr-flash。
- 游戏不会在真实模型失败时用 Mock 内容冒充成功；鉴权、余额、限流、网络或服务异常会显示真实错误。
- 设置页可以切换为玩家自己的 DeepSeek / OpenAI-compatible 服务；玩家 Key 由本机 Windows 凭据保护层保存。

常见问题
========

- 提示端口 5000 被占用：请关闭正在运行的开发后端或其他试玩实例后重试。
- 提示后端启动失败：请确认目录完整，检查安全软件是否拦截 backend/ThisIsNotMyWarBackend.exe。
- AI 暂时失败：非 AI 基础玩法仍可继续；稍后重试或在设置中检查 AI 服务。
- 语音识别失败：可以继续使用文字输入，不影响对话主流程。

本机数据
========

试玩版设置、存档和后端日志保存在当前 Windows 用户的本机应用数据目录中，不写入游戏安装目录。

完整性
======

BUILD_MANIFEST.json 记录本次构建版本及文件 SHA-256，可用于确认文件是否完整。请勿单独替换 game/、backend/ 或启动器。
