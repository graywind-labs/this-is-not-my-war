# sample_pack_v22_bgm_day_night

本包最初用于试听；T0378 已按用户确认把白天 01 / 03 / 04 / 05 / 07 / 12 与夜晚 05 / 06 / 10 正式接入游戏，其余仍为未采用候选。

- `day/`：白天 12 首，01 是当前正式曲的响度统一参考，02–12 是候选。
- `night/`：夜晚 12 首，01–03 是上一轮因“昼夜共用”而暂未采用的候选，04–12 是新增候选。
- 全部试听副本统一转为 MP3、48 kHz、双声道、约 -20 LUFS，便于直接比较。
- `raw/` 保存下载原件或上一轮源文件副本，试听时不用进入。
- 双击单个 MP3 即可播放；播放器支持 M3U8 时可打开 `day_candidates.m3u8` 或 `night_candidates.m3u8` 连续试听。

## 建议先听

白天先听：01（当前参考）、04、05、06、07、03。09 / 10 很轻，但只有约 14.5 秒，连续循环可能容易重复；12 更像村庄广场小曲，节奏更明显。

夜晚先听：02、03、05、06、08，再听 01、10。07 / 09 / 12 更暗，适合判断夜晚是否需要增加压迫感；10 / 11 更安静，但钢琴和现代环境纹理可能弱化中世纪质感。

回复选择时请写成：

```text
白天：01、04、05、06、07……
夜晚：02、03、05、06、08……
```

正式选择已记录在 `SOURCES.csv` 的 `decision / final_usage / edit_instruction`；九首运行时文件和母版分别位于 `assets/audio/music/{day,night}/` 与 `art_source/audio/masters/music/{day,night}/`。
