# sample_pack_v26_ambient_nature_beds

T0389 第二轮昼夜自然环境底噪候选。根据用户反馈，候选必须保留真实自然生命声，而不是纯风声。

- `day/`：5 条“环境底层 + 鸟叫”真实野外录音，统一整理为单声道、48 kHz、约 `-28 LUFS` 的试听版。
- `night/`：5 条正常夜间虫、蛙自然录音，统一整理为单声道、48 kHz、约 `-30 LUFS` 的试听版，避免按原始响度直接抢耳。
- `raw/`：Freesound 官方 HQ preview，仅供选材与来源留档。
- 用户已确认白天 04、夜晚 01；`selected/` 保存由对应 60 秒试听段制作的循环接缝母源，其余条目继续作为候选存档。
- 正式运行时分别以 `-28 LUFS / -30 LUFS` 制作，保持试听时的克制响度。

第一轮 v25 纯风候选已被用户整体否决，不进入正式资产。
