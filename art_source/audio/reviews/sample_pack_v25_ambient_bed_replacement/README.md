# sample_pack_v25_ambient_bed_replacement

T0389 昼夜主环境底噪重选试听包。候选均不含鸟、羊、虫或其他动物声。

- `day/`：5 条白天候选，统一整理至约 `-27 LUFS`，保留较明亮的空气高频。
- `night/`：5 条夜间候选，统一整理至约 `-29 LUFS` 并压暗高频，降低夜晚干扰。
- `raw/`：对应原始下载源；只有用户选定后才进入正式母版和 `assets/audio/`。
- `day_candidates.m3u8`、`night_candidates.m3u8`：可用 VLC 连续试听。

当前正式昼夜底噪暂时保留原文件；本包所有条目已按用户反馈标为 `rejected`。
