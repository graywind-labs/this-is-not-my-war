# sample_pack_v28_tutorial_bgm

本包用于选择新手引导的两首独立 BGM，依据 `docs/TUTORIAL_DESIGN.md` 的约 3 分钟序章流程整理。用户已于 2026-09-12 整批否决，原因是“都太有史诗感，不符合游戏稍微轻度一些的体验”。全部文件仅保留作否决记录，未进入正式 manifest、运行时资产或程序映射。

- `intro_still/`：四帧漫画与艾达报讯阶段。目标是深夜、军令、孤立和迫近威胁；低动态，不抢字幕。
- `main_tutorial/`：进入 3D 主场景后至战后交接。目标是克制备战、短促夜袭和带希望的余波；不能像正式大战 BGM 一样持续顶满。
- `raw/`：下载原件，试听时不用进入。
- 试听副本统一为 MP3、48 kHz、双声道、约 -20 LUFS，便于直接比较；没有为试听包改动原曲结构。

## 建议先听

静止帧先听：01、03、02。01 最像安静悬念，03 更像失守后的冷清世界，02 更偏电影序章。04 情绪和编制较大，05 很短且直接，06 更接近恐怖环境音乐。

主场景先听：01、05、06。01 有完整的中世纪战争叙事弧线，05 是短而紧的敌军迫近，06 最能覆盖部署到战斗的长段落。02 更明快，03 更英雄化，04 鼓点和行军感最突出。

回复选择时请写成：

```text
静止帧：01
主场景：05
```

选定后再制作正式 48 kHz BGM：归入 Music，总体响度按现有 BGM 标准；整首循环，开头与结尾各做约 2 秒渐入 / 渐出。静止帧曲在切入 3D 时交叉淡出，主场景曲持续到第 1 日 06:00 交接完成后再交给正式昼间音乐。
