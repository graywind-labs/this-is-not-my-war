# sample_pack_v27_building_craft_audio

建筑施工与铁匠铺交互音效试听包。用户已确认短木击 05、施工循环 01、铁匠敲击 04；建筑升级完成复用既有 NPC 升级成功声。

- `01_short_wood/`：点击“升级 / 修复”成功开始施工时使用的短促敲木声候选。
- `02_construction_loop/`：建筑处于升级 / 修复期间，从建筑位置持续播放并随镜头距离衰减的施工循环候选。01 是游戏当前已有素材。
- `03_blacksmith_select/`：铁匠铺成功选定制造目标时播放一次的短促敲铁声候选。01 是从当前打铁循环首击剪出。
- `04_completion_reference/`：NPC 升级现用成功铃声；按用户要求拟直接复用于建筑升级完成，不需要重新选材，但保留试听参考。

接入合同：修复 / 升级成功受理时从建筑位置播放短木击；建筑权威修复 / 升级任务存在期间从建筑位置循环施工声并按本地 3D 距离衰减、开停渐入渐出；只有升级完成播放既有 NPC 升级成功声；铁匠铺成功选定非空制造目标时从建筑位置播放敲铁声。失败请求、程序刷新、重复选择与清空目标均静音。
