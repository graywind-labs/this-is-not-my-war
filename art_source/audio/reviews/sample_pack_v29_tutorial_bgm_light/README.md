# sample_pack_v29_tutorial_bgm_light

这是用户否决 v28 的史诗方向后重新整理的轻度版新手引导 BGM 试听包。2026-09-12 已确认静止帧 06、主引导 01，并将主场景 02 / 04 / 06 分别加入夜间 / 日间正式轮播；其余文件继续仅供试听。

- `intro_still/`：四帧漫画和艾达报讯。只保留小编制、缓慢旋律或很轻的等待感，不使用合唱、重铜管、英雄主题和行军鼓。
- `main_tutorial/`：进入 3D 主场景后至战后交接。允许一点轻节奏，但整体仍像轻度经营 / 教学段，不做大战或预告片感。
- `raw/`：下载原件或旧试听包的原始来源副本。
- 试听 MP3 统一为 48 kHz、双声道、约 -20 LUFS，只统一格式和响度，不改变原曲结构。

## 建议先听

静止帧先听：05、01、04。05 最安静且有夜间城堡感；01 像轻柔叙事日记；04 只有一点等待和不安。02 更舒展，03 是很短的小型中世纪循环，06 有轻微夜行感。

主场景先听：02、01、03。02 是较完整但不宏大的中世纪游戏曲；01 有轻战斗节奏；03 更像轻松的小型驿站主题。04、05 更接近日常游戏 BGM，06 最明亮。

回复选择时请写成：

```text
静止帧：05
主场景：02
```

正式规则：静止帧 06 从序章开始循环，到 `intro_ada_warning` 前为止；进入艾达说“守备官！小路远处有火光出现……”的当前页时交叉淡入主引导 01。01 随后连续贯穿余下漫画、3D 教程、战斗及战后交接，不因漫画转 3D 重新起播。全部正式曲归入 Music，首尾各烘焙约 2 秒淡化。
