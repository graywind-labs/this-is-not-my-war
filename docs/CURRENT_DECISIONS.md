# CURRENT_DECISIONS.md

> 记录当前已经确定、但可能未来变更的设计和技术决策。  
> 若用户明确推翻某项决策，更新本文件。

## 已确定

1. 项目使用 Godot 4.6。
2. 推荐使用 Godot 前端 + Python 后端 + deepseek-v4-flash API。
3. 玩家没有可移动角色，是上帝视角守备官。
4. Demo 初始 8 名 NPC。
5. NPC 不死亡，HP 清零后昏迷。
6. 医生可加速治疗昏迷 NPC。
7. HP 恢复到 30% 后复苏。
8. 广场是公共信息中枢。
9. 战斗关键事件进入广场见闻系统。
10. 开局只有老兵副官可被玩家指派。
11. 其他 NPC 需要通过对话同意应征后才能被指派。
12. Demo 胜利条件为守住 5 波敌人。
13. 主厅被摧毁为硬失败条件。
14. 事件系统是信息产生、记录和传递的底层系统；每个事件关联 NPC、地点、可见性和结构化 payload。
15. NPC 当天短期记忆由事件库和见闻库组成，二者分开保存。
16. 主厅、围墙、城门不可进入；它们的状态归入广场信息空间和 NPC 进入广场时的地点状态快照。
