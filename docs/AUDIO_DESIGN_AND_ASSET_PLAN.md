## 1. 声音目标

声音需要把“边境驿站压力锅”做出来，而不是把驿站包装成热闹、轻松的模拟小镇。

- 时代质感：木、铁、石、皮革、布料、泥土、火焰和手工机械为主，不出现现代机械、电气或电子提示音。
- 经营可读：玩家不看面板，也能从方向和材质判断附近正在打铁、做饭、耕作、治疗还是训练。
- NPC 有人格：回复不配完整语音，只用不含词语的一声短促语气音表达当前回复情绪，避免和 AI 文本抢注意力。
- 战斗有层级：攻击动作、武器接触、人物受击、建筑受击和倒地分层制作，不能用一个“打击声”覆盖全部结果。
- 克制而紧张：日常音乐留出大量空间，夜晚更空、更冷；敌人真正出现在场景里后，战斗音乐才接管。
- 低重复感：高频短音效采用小型变体池、轻微音高与音量随机、同一变体短时间防重复。

## 2. 空间、时长与播放原则

### 2.1 2D / 3D 声音边界

| 类型 | 空间方式 | 说明 |
|---|---|---|
| 菜单与背景音乐 | 2D、非定位 | 不随镜头位置变化；场景音乐之间交叉淡化 |
| 昼夜主环境底噪 | 2D、非地点定位、随镜头缩放 | 全场始终可闻；20–64m 镜头距离由 100% 降到 30%，最远不归零 |
| 局部环境音效 | 3D、定位 | 鸟、鸡、猫头鹰、虫群、河流和火源挂在真实环境位置或环境发声区 |
| 工作、脚步、核心实战声、建筑、陨石 | 3D、定位 | 从实施动作的 NPC、工位、投射物接触点、受击角色 / 建筑或技能落点发声；核心实战声使用更强的战斗可闻性档 |
| NPC 回复情绪语气 | 2D、非定位 | NPC 面板 / 对话回复时直接播放，不随 NPC 与镜头距离衰减；仍走 Voice 总线 |
| UI | 2D、非定位 | 按钮、面板、确认和拒绝属于屏幕反馈，不随世界镜头衰减 |
| 人物成长提示 | 2D、非定位 | 升级获得技能点与成功分配属性点复用成功钟声，受点击音效音量控制 |
| 虔诚蓄满提示 | 2D、非定位 | 选定 v24-05；5 秒全局 Combat 单次声，最后 1.5 秒渐出 |
| 战局状态提示 | 2D、非定位 | 警报、敌人入场 / 战斗开始、单波清除、最终胜利与失败不绑定地点、不随镜头衰减 |

镜头越近，普通 3D 声音越清晰、越响；越远则自然衰减。T0375 起普通局部声把清单 `suggested_max_distance_m` 作为地面基础听距，运行时乘 `4`，使用 `unit_size=12m` 的逆距离曲线。T0376 起挥动 / 释放、破风、命中、敌我受击语气、倒地及结构受击改用 `combat_priority`：`unit_size=48m`、最远距离至少 `480m`，并关闭默认 `-24dB` 远距低通，解决俯视相机高度本身导致的过度压低，同时保留左右方位。

- 脚步：基础约 `12–18 m`，实际约 `48–72 m`。
- 工作 / 门 / 小型道具：基础约 `18–28 m`，实际约 `72–112 m`。
- 核心战斗 / 人物与结构受击：实际最大听距至少 `480m`，48m 内不因距离压低，远处仍按逆距离缓降。
- 警报 / 入场 / 清波 / 胜负：全局 2D，不存在距离听距。
- 陨石下坠与爆炸：T0381 起使用大招专用档，参考距离 `120 m`、最大听距至少 `1500 m`、无远距低通，仍以实际陨石 / 落点为中心；下落 / 冲击另增 `+2 / +3 dB`。

### 2.2 时长原则

- 背景音乐：主场景昼夜曲为完整非循环单曲，按池顺序播放并在首尾各烘焙 `2 s` 淡化；菜单 / 战斗曲保持单曲循环。
- 环境循环：`30–90 s`，必须无明显循环接缝；鸡鸣、鸟叫、猫头鹰等使用 `0.6–3.0 s` 的随机单次声。
- 普通短音效：以 `0.08–1.5 s` 为主。
- 警铃、倒塌、陨石等重型事件：`1.5–6.0 s`，允许保留短尾响。
- NPC 情绪语气：`0.25–1.10 s`，不含可识别词语、名字或语言音节。

### 2.3 高频播放保护

- 当前确认的工作 / 持续日常素材在真实 active 行动期间循环，并在开始 / 结束时渐入渐出；同一语义地点只保留一条，避免多人把相同素材同相叠加。
- x2 / x4 时间倍率不改变音频音高，也不把全部逻辑事件逐个压缩播放；只播可见动作或经过密度限制的代表性声音。
- 同类脚步、打铁、弓箭和群体受击设置并发上限；超限时优先保留距镜头近、重要度高的声源。
- 48 名敌人同时存在时，不允许 48 条相同脚步或呻吟满额叠加。

## 3. 背景音乐清单

整体配器建议使用低音提琴 / 大提琴持续音、手鼓、框鼓、低音弦拨奏、木笛、古提琴、鲁特琴、少量钟琴与粗粝环境纹理。避免现代大片铜管、电子合成器、过度明亮的欢乐民谣和持续轰炸式战鼓。

| ID / 用途 | 条数 | 单条时长 | 声音设计 |
|---|---:|---:|---|
| `music_menu` 开始 / 加载 / 设置界面 | 1 | 90–150 s | 稀疏鲁特琴与低弦，带一点“军令将至”的不安；可停留很久，不制造疲劳 |
| `music_day_playlist_*` 白天经营 | 6 | 44–255 s | 01、03、04、05、07、12 按编号轮播；温暖克制的木质拨弦、木笛、弦乐与竖琴 |
| `music_night_playlist_*` 夜间 | 3 | 120–256 s | 05、06、10 按编号轮播；更少节拍、更低动态，以冷调弦乐、钢琴和大提琴保留孤立感 |
| `music_combat` 敌人已出现在场景中 | 1 | 120–180 s | 低鼓、急促弦乐节奏和粗糙持续音；强度高于日常，但给武器和警铃留出频段 |

正式播放逻辑：白天 6 首、夜晚 3 首按上表顺序循环轮播，每首自然结尾先淡至静音再由下一首从静音淡入；昼夜边界以 `2 s` 交叉淡化切换对应池。敌人真正进入场景后由循环战斗曲接管；最后一名敌人离场后继续当前时段播放池的下一首。来袭预告阶段只用警铃 / 号角，不提前进入完整战斗曲。

## 6. NPC 回复情绪语气声

当前程序已有 9 个正式情绪 ID，音效必须逐项对齐，不自行新增同义枚举：

| 情绪 ID | 中文 | 每套条数 | 时长 | 语气要求 |
|---|---|---:|---:|---|
| `none` | 无明显情绪 | 1 | 0.25–0.55 s | 中性鼻息或轻应声，不表达赞同 |
| `happy` | 开心 | 1 | 0.35–0.80 s | 短促明亮的小笑 / 欣喜呼气，不大笑 |
| `relieved` | 放松 | 1 | 0.45–1.00 s | 明显松一口气 |
| `angry` | 愤怒 | 1 | 0.30–0.75 s | 压低的怒哼或短喝，不说词 |
| `sad` | 难过 | 1 | 0.55–1.10 s | 下沉呼气、轻哽咽，但不戏剧化哭喊 |
| `afraid` | 害怕 | 1 | 0.30–0.85 s | 倒吸气或压抑惊惧声 |
| `surprised` | 惊讶 | 1 | 0.25–0.65 s | 短促吸气 / 惊声，不出现“什么”等词 |
| `confused` | 困惑 | 1 | 0.35–0.80 s | 轻疑问哼声，尾音上扬但无语言 |
| `determined` | 坚定 | 1 | 0.30–0.75 s | 收紧呼吸、低声确认感，不做英雄口号 |

P0 先制作两套基础声线：一套偏低沉粗粝、一套偏清亮克制，共 `9 × 2 = 18` 条。运行时按人物基础声线映射，并做极轻的音高差异，不能用大幅变调制造怪声。

P1 正式目标是 8 名 NPC 每人一套专属声线，共 `9 × 8 = 72` 条；相对 P0 新增 54 条。这个升级值得保留，因为“NPC 是具体的人”是本项目核心，最终版本不应让所有人共用同一个开心或害怕声。

敌人受击呻吟不复用这 9 种对话情绪，也不会触发情绪 Emoji。

## 13. 音频格式与导入标准

- 原始母版：`48 kHz / 24-bit WAV`。
- 3D 短音效：单声道 WAV；移除不必要静音，保留自然尾响，不把空间混响永久烘得过重。
- UI 短音效：单声道或窄立体声 WAV，优先低延迟。
- 音乐：立体声 OGG Vorbis，保留 WAV 母版；循环点必须实测无爆音。
- 长环境循环：优先 OGG；定位环境单声道，只有确需固定宽度且经实现确认的环境床才使用立体声。
- 所有文件进入运行时目录前做峰值、底噪、直流偏移、首尾爆音和循环接缝检查。
- 不用强压限幅把所有素材做得一样响；短音效保留瞬态，音乐与环境保留动态。

建议相对响度基线不是最终硬数值，接入后以实机混音为准：

- 音乐约 `-18 至 -14 LUFS-I`。
- 环境约 `-26 至 -20 LUFS-I`。
- 普通工作 / 脚步短音低于战斗核心反馈。
- 陨石、警铃和建筑倒塌允许瞬时更突出，但总线峰值必须留安全余量。


正式设置界面提供主音量、音乐、点击音效、语气音效、战斗音效、工作音效、环境音效七项。设置保存为 schema v2；音乐缺省 28%，其余缺省 80%。旧 v1 配置只迁移一次：音乐实际值乘 0.5，旧 SFX 分别继承给 Voice / Combat / Work，旧 UI 继承给点击，环境保持原值。静音 `0%` 会设置对应总线 mute；拖动实时生效，松手播放木质点击作为操作确认。

## 15. 试听与验收标准

每批资产先在文件级试听，用户确认后才进入程序接入阶段。

### 15.1 文件级验收

- 文件名、数量、时长、格式与清单一致。
- 无削波、爆音、明显底噪、错误声道和循环接缝。
- 同一组变体材质统一，但瞬态、力度或细节确实不同，不是简单复制后改音量。
- NPC 情绪声不包含能被听成中文、英文或姓名的词。
- 第三方 / 生成素材来源和商用许可可追溯。

### 15.2 游戏内验收（方案确认并完成接入后执行）

- 镜头靠近 / 远离声源时音量连续变化，左右方向正确；离开最大距离后不残留。
- 白天、夜晚、战斗和菜单音乐切换无突变、重叠失控或循环断点。
- 8 名 NPC 的工作动作能听出职业差异；9 种回复情绪能与 Emoji 语义一致。
- 步行、奔跑、马匹和四类地表至少能正确区分。
- 剑、长杆、弓、弩、弩床、箭塔、人物受击、木结构受击和石结构受击彼此可辨。
- 陨石能听出下坠震动、逼近和落地“轰”的时间关系，声音从落点而非镜头中心出现。
- x2 / x4、LLM 慢速、48 敌和多个工位同时工作时没有不可控叠音。
- 设置界面音量滑杆实时生效，保存 / 读档或重启后保持。
