## 结论与随机性边界

- 每个正式场景使用 2～3 个同义改写样本；这些结果是模型采样的验收样本，不是公开概率，也不是程序硬编码概率。
- 开局通用话术由基线 10 / 14 接受降为最终每轮 0 / 7，符合每轮 0～2 人接受的目标；单项建筑信息只有布鲁诺食堂路线出现 1 / 3 接受，完整路线则每人多数接受。
- 逃离由目标 NPC 当时确实可知的建筑、资源、人员、装备、指令、攻击、承诺与战况事实驱动；实际解决原因明显优于空话或无关礼物。
- 欧文在“只改指令 / 给装备但结构与材料问题仍未解决”时仍可能离开，符合其工程安全边界；艾达保持稳定锚点。

另行通过真实 provider 回归：计划修改范围判别、正式计划修订与增强后的熟睡反思（诊所、护甲、职责承诺兑现以及酒仅为礼貌）均首次成功。其调用不计入上表 180 次正式行为矩阵。
