## 2026-08-26 T0135-P6R2 阴影方向时间采样（已被 P6R3 覆盖）

一分钟的天体角位移很小，设计上接受轻微、低频的日影位置步进，换取墙角、屋檐、树木与地表阴影在片段内完全稳定。若本轮仍有高频波动，则不再继续扩大采样间隔掩盖问题，而应转查具体材质透明抖动、重叠投影或 GPU 阴影深度精度。

## 1. 规划目标与不可变原则

### 1.1 目标观感

- 参考用户提供的《奔奔王国》画面：远景先读建筑轮廓与完整屋顶，近景屋顶渐隐后直接读室内设备、NPC 和动作；升级不是数字换色，而是房体、设备、平台或工位真实增加。
- 保持 Quaternius 的低多边形、玩具模型感和粗壮轮廓，不复制参考图中的具体建筑、布局、图标或材质。
- 驿站仍是一个被战争压迫的封闭据点，不扩张成开放世界。更大的空间用于建立道路、呼吸区、升级容量、敌人入场和可信的自然边界。
- 地图边缘不依赖裸露绿色平面或突兀空气墙。河流、悬崖、岩脊、密林和雾共同包围可玩区，只留下正门敌军入口与后门商旅通道。

### 1.2 空间与权威的硬规则

1. `1 Godot unit = 1 m`，`+Y` 向上，角色视觉前向为 `-Z`。
2. 场景原点 `(0,0,0)` 保留在驿路交汇区附近，不再要求它是几何广场中心；`+X` 为东 / 画面右，`-X` 为西 / 画面左，`+Z` 为正门和敌军方向，`-Z` 为后门和商人方向。
3. 建筑从 Lv.1 起就保留其最高等级所需的完整地块。Lv.1 可以只建成部分房体，剩余位置用基础、木桩、材料堆或封闭扩建区表达，但不能被道路或其他建筑占用。
4. 每个权威功能位置必须一一对应：`可见设备 / 家具` + `同 ID Marker3D` + `NPC 实际站位与朝向` + `BuildingSystem reserved_by / occupied_by`。
5. 未解锁位置不得提前摆出可被误认为能工作的同类完整设备；只提高 HP / 效率的等级可以增加加固、烟道、储物、照明或工具，但不能增加功能位置 Marker。
6. NPC 只有实际穿门后才算进入建筑，只有抵达具体 Marker 后才算占用并开始循环动作。模型不能用后台地点字段替代实际移动。
7. 任何建筑、道路、环境、镜头或敌人入场的空间决定发生变化，都要在本文件的“变更记录”中说明原因和影响。
8. 建筑正面只允许使用北、东北、东、东南、南、西南、西、西北八个方向，即绕 `+Y` 每 `45°` 一档；不允许任意 `4–11°` 小角度造成杂乱朝向。地块位置仍保持错位、不等距和非对称。

| 病床 | `2.2 × 3.0 m` | 一张真实病床、上下床边和患者 Marker |
| 教官 / 训练位 | `3.0 × 3.0 m` | 教官观察区或一套假人 / 靶 / 练习设备 |
| 宿舍床位 | `1.3 × 2.4 m` | 一张可辨认床 / 铺位和对应睡眠点 |
| 祈祷席 | `0.9 × 1.5 m` | 一个明确坐 / 跪位置，朝向祭坛 |

同类 Marker 中心建议至少相距 `1.8 m`；NPC 当前导航半径约 `0.35 m`，家具碰撞、角色胶囊和工作动画四肢摆动都必须留在单元净空间内。多人可见动作不得互相穿透墙、炉体、床或另一名 NPC。

### 6.2 运行态一致性验收

一个位置只有同时满足以下条件，画面才允许表现为“有人在工作”：

1. `BuildingSystem` 中该位置的 `occupied_by == npc_id`；在途只能显示 `reserved_by`，不能提前开始工作动画。
2. NPC 世界坐标到同 ID Marker 的平面距离目标值不大于 `0.35 m`。
3. NPC 视觉前向与工作对象方向的点积目标值不小于 `0.85`。
4. ActionSystem 已进入对应 active 行动，表现层才循环播放锻造、烹饪、耕作、诊疗等动作。
5. 行动中断、建筑封闭、昏迷或改派后，权威位置先释放，表现层立即退出工作循环并执行真实离开路线。

每座建筑的逐级自动验收至少比较：

```text
building_defs / BuildingSystem 当前权威位置 ID 集合
        == 场景中当前可见且启用的 Marker ID 集合
        == 当前可被识别为功能位置的设备 / 家具 ID 集合
```

升级新增功能位置时，设备、Marker、碰撞、导航净空和动作朝向必须在同一级同时启用；只提升 HP / 效率时，以上集合不得增长。

## 7. 城外自然边界与非建筑内容

### 7.1 自然阻挡环

- 西侧河流贯穿 `Z[-335,385]`，中心约在 `X=-97` 左右轻微弯折；常水面宽 `7–11 m`，真实河槽宽 `24–34 m`。驿站地坪为 `Y=0 m`，河面为 `Y=-1.2 m`，两岸必须是彼此断开的地形网格，并以不规则土石坡 / 崖壁下落到水面。禁止用贯穿全图的直线蓝盒作为最终河流，也禁止任何无设计语义的草地、道路补片或地面盒横在水面上方。河流、陡岸和外侧岩石不进 NavMesh。
- 东侧山体的可通行山脚仍从约 `X=120` 开始，但可见美术必须填满到地图右边界 `X=350` 并在镜头视锥外继续收口：近层 `X[120,175]` 为 `4–8 m` 低岩台 / 实体阻挡，中层 `X[165,255]` 为 `10–18 m` 叠岩 / 针叶林，远层 `X[235,350+]` 为 `18–35 m` 连续山脊 / 林冠。三层在 `Z[-360,385]` 贯通并错开轮廓，不能再把宽 `55 m`、高 `5.5 m` 的四段碰撞盒当成整座山。
- 后侧边界覆盖约 `X[-344,344] / Z[-329,-60]`，以断崖、密林和低雾封闭，只沿后门到南侧地图边缘的长折线通道切出峡口。
- 前侧边界：两侧密林、巨石与雾围合，中间保留敌人进攻廊道；玩家能看见敌人从林中走出，但看不见生成瞬间。
- 森林散布包络为 `X[-344,344] / Z[-329,379]`，距 `700 × 720 m` 承底四边约 `6 m`；T0129A 独立规划灰盒曾以 1043 个 MultiMesh 树实例证明全幅包络，但当前正式场景并未迁移该密度，只在 12 个碰撞段上生成约 71 棵程序圆柱树。T0135 必须改为 Quaternius 树 / 岩 / 植被的分块 MultiMesh 与近景实体组合，让树木、岩石与雾继续到镜头边缘之外。
- 自然边界全部需要静态碰撞或明确 NavMesh 排除。空气墙只作防穿越兜底，不能是玩家看到的主要边界。

Quaternius `CommonTree_1` 当前实际 AABB 约 `4.31 × 7.27 × 4.58 m`。树干中心至少离可走道路边缘 `3 m`；密林可以互相重叠树冠，但树干碰撞和导航阻挡不能侵入主路。远景密林优先采用简化碰撞、MultiMesh / LOD 和雾遮挡，不能给每片叶卡建立碰撞。

### 7.2 T0135 可见自然层与物理层拆分

正式环境不再从 `natural_collision.barriers` 直接生成最终美术。三层职责固定为：

1. `Terrain Topology`：河槽、两岸、东侧山脚和必要的高差，决定水土关系与宏观轮廓。
2. `Natural Art`：树群、岩群、林冠、草丛、河岸植被、雾和杂物，决定遮蔽、密度和近中远景精细度；除玩家可接近的大树干 / 巨石外默认无碰撞。
3. `Physical Boundary`：现有 24 个简化 StaticBody / NavMesh 排除段继续作为低成本阻挡兜底，视觉默认隐藏；美术更新不得改变正门敌路、后门商路、长逃离或 61 个工位路径。

本地 Stylized Nature MegaKit Standard 已有 68 个 glTF 候选：20 树木（Common / Twisted / Dead / Pine）、24 岩石 / 卵石、24 灌木 / 草 / 花 / 蕨类。首次运行时筛选的目标不是全部摆满，而是建立每区 3–5 个主型、2–3 个辅型和统一色板：驿站内以 Common / 少量枯树和低草为主，前方敌林以 Pine / Twisted / 深色灌木为主，河岸以卵石 / 蕨类 / 高草为主，东侧山体以 Pine / 中型岩石为主。

密林用 `32–48 m` 地块分块 MultiMesh，避免单个超大全图 MultiMesh 因整体包络导致不可细粒度剔除。近层树才投射完整动态阴影并按需保留树干胶囊；中层关闭个体碰撞并减少阴影；远层以低模树冠体块、简化山体和雾建立连续剪影。草地以地表材质为主、草簇为辅，不逐根实例化整张地图。

### 7.3 城内环境内容与留白

- 至少保留约 `20–25%` 墙内面积为分散的草地、泥地和可读留白，不用道路或杂物填满每个缝隙，也不把留白合并成一个巨大中心广场。
- 驿路交汇：水井、公告牌、警钟、少量长椅、柴车 / 推车和物资箱沿三个泥地口袋的边缘排布；中心只保留 NPC 交谈 / 集结所需的小型通行净空。
- 仓库周边：货车、木箱、麻袋、装卸坡道和车辙。
- 马厩周边：草垛、围栏、料槽、拴马柱和泥泞地面。
- 铁匠铺周边：煤堆、矿石、废铁、冷却水桶和安全隔离的火星 / 烟尘区域。
- 诊所周边：药草架、晾晒布、清水桶；教堂周边：花丛、小型纪念石或墓碑；食堂周边：柴垛、桶和食材箱。
- 菜园：围栏、灌溉沟、堆肥和生长阶段差异；训练场：假人、盾靶、武器架和沙土地。
- 杂物不得进入门外 `4 × 4 m` 前坪、功能位置单元、主要通道或建筑点击轮廓；装饰不拥有资源、工位或事件权威。

### 7.4 驿站内地表与广场制作合同

城内地表不是独立浅色地块，而是全图同一深草生态经过人类长期踩踏后的局部变化。表现从下到上分七层：

1. `Deep Grass Base`：继续使用 `#405842` 附近的低饱和深绿，不改变现有 `Y=0` 导航地坪。
2. `Grass Macro Variation`：用世界坐标低频噪声在 `#354c3a / #405842 / #465f46` 之间缓慢变化，同时小幅改变粗糙度；变化尺度 `12–28 m`，不得形成可辨认方格。
3. `Compacted Dirt`：道路、广场、门前和高频工作区使用灰褐 `#625847 / #70634f`，以低模贴地网格 / Shader 蒙版覆盖，不改变碰撞。
4. `Wear And Drainage`：在门槛、车轮转弯、炉棚 / 马厩周边增加深色湿痕、浅凹排水线和不连续脚踩磨损；不做深沟碰撞。
5. `Road Integration`：既有 FormalRoadNetwork 的泥肩与地表泥色共用色板，路肩外沿插入草地，不再像单独铺上去的胶带。
6. `Embedded Detail`：使用 Quaternius `Pebble_Round_1–5 / Pebble_Square_1–6 / RockPath_*`，只在边缘和低洼处稀疏出现，Y 贴地且无碰撞。
7. `Vegetation Clumps`：使用 `Grass_Common_Short/Tall`、`Grass_Wispy_Short/Tall`、`Clover_1–2` 和少量 `Plant_1`，避开道路核心、门坪和人物交谈区。

广场权威仍是 `position=(0,10) / radius=4 m`，但表现包络约为 `14 × 12 m` 的不规则泥地交汇口。旧 `(-2,9) 9×6 / (3,11) 7×5 / (-1,14) 6×4` 三个浅色 Box 只保留为历史配置输入，不再逐块渲染；新网格取三块包络和相邻道路端点的并集，生成一个带 `1.2–2.0 m` 羽化边缘的连续非矩形表面。中心至少保留 `8 × 6 m` 平整无实体装饰区供 NPC 会面、事件广播和临时集结；公告牌、未来水井、少量坐具和物资只能沿边缘落位。

阈值继续由统一 `RoofVisibilityController` 驱动，并按建筑覆盖。渐隐时关闭实体屋顶阴影，但墙、碰撞、导航、点击、地点和工位不变。近景必须让同一建筑最高等级的全部位置和 NPC 动作可辨认；如果外墙遮挡，优先采用局部矮墙、剖切方向或材质渐隐，不把 NPC 传到屋外假装室内工作。

### 9.3 太阳 / 月亮天体循环

环境控制器只读 `GameState` 的 `day/hour/minute/second` 与 `EventBus.time_changed`，把一天换算为 `0–1` 归一化时刻。首轮采用固定季节参数，不引入纬度 / 季节玩法：太阳 `05:30` 从地图东侧 `+X` 升起，`12:30` 到南侧天空 `-Z` 最高约 `52°`，`19:30` 从西侧 `-X` 落下；月亮约 `18:30` 东升、`00:30` 最高约 `42°`、`06:30` 西落。

天体方向通过“东点—南天最高点—西点”的连续球面轨迹计算，不能只改变 DirectionalLight 的亮度而保持阴影方向不动。太阳 / 月亮低于地平线 `-6°` 后对应直射能量归零；在 `-6°–+10°` 的暮光区间使用 smoothstep 控制能量和颜色，避免日出 / 日落跳变。太阳主能量白昼约 `1.25–1.6`，月亮最高约 `0.22–0.35`；日月同时接近地平线时只让能量更高者投主阴影，另一者保留极弱无影填光，禁止双重硬阴影。

调色锚点由太阳高度而不是整点决定：

| 太阳高度 | 视觉阶段 | 光照 / 环境关系 |
|---|---|---|
| `>10°` | 白昼 | 中性偏冷太阳、较高环境光、低雾密度 |
| `0°–10°` | 日出 / 黄金时段 / 日落 | 太阳逐步转灰橙 / 脏金，阴影拉长并偏冷，雾获得轻微太阳散射 |
| `-6°–0°` | 民用暮光 | 太阳直射快速衰减，天空从暖地平线过渡到蓝灰，火把 / 室内灯开始接管 |
| `<-6°` | 夜晚 | 月亮高度决定冷色直射；环境光保持低但不死黑，边界雾增强 |

暂停后天体完全静止；x2 / x4 只随 TimeSystem 的真实游戏时刻加速，不自行维护第二套计时。GM 继续使用已有 `set_time <day> <hour> <minute> <second>` 跳转测试，读档 / 新游戏时按当前绝对时刻一次同步，不依赖上一帧累计角度，避免存读档后日月位置漂移。

### 9.4 天空、雾、功能灯与室内可读

`WorldEnvironment + ProceduralSkyMaterial` 根据太阳高度连续更新天空顶部、地平线、地面反照、环境能量、色调和雾；不是四张预设突然切换。默认低配路径使用传统深度 / 高度雾；Forward+ 高质量档只在河谷、前后林缘和东侧山脚使用少量 FogVolume，不开启覆盖全图的高密度体积雾。

主路口、正后门、公告牌和建筑入口的火把 / 灯笼强度由太阳高度反向驱动：太阳降到 `+3°` 以下开始渐亮，低于 `-6°` 达到夜间强度，日出反向渐灭；铁匠炉、食堂灶火等生产火源继续只读真实建筑 / 行动状态，不因白昼被强制熄灭。可进入建筑在屋顶 / 外墙 alpha 降低时，室内环境填光随透明度轻微补偿，并让必要的桌灯、炉火、祭坛烛光继续照亮人物和工位；不通过抬高全场曝光或让室内材质整体自发光来伪造可读性。雾不得进入近景室内形成灰幕。

## 10. 素材尺寸与制作合同

- 建筑结构继续使用 `2 m` 主模块；标准层高约 `3.125 m`，墙厚参考 `0.406 m`，参考门扇 `1.12 × 2.318 m`。

- AI 生成图像可用于 UI、图标、材质 / 贴花草案和概念对照，不用于需要精确 3D 占地、碰撞、骨骼、导航或工位对应的建筑主体。
