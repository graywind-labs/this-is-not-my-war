## 建筑通用属性

| 属性 | 说明 |
|---|---|
| 建筑等级 | 影响产出、容量、效率或防御能力 |
| 建筑生命值 | 被攻击时下降，归零后失效或摧毁 |
| 工作位数量 | 可同时进行相关工作的 NPC 数量 |
| 当前占用状态 | 哪些工作位被谁占用 |
| 信息空间 | 记录建筑内发生的事件、状态与人物见闻 |

## 主厅

玩家所在地和驿站指挥中枢。不可进入或不作为常规可操作建筑。  
主厅被摧毁则失败。

## 小诊所

医生在此治疗病人、研究医术。  
治疗消耗金钱。  
NPC 昏迷后可由医生治疗以更快恢复 HP。  
NPC HP 恢复到 30% 后复苏。

## 仓库

储藏资源。  
敌人攻击仓库会造成资源流失。  
仓库等级影响容量和被掠夺损失比例。

## 围墙

敌人攻入驿站前需要先破坏围墙或城门。  
可消耗石料修复或升级。  
工程器械可部署在围墙上。
