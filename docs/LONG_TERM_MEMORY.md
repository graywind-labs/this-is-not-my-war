# LONG_TERM_MEMORY.md

> 记录长期稳定规则、踩坑、架构约束。  
> 这里的信息用于防止 Agent 反复犯同样错误。

## 稳定规则

- 不要把项目做成大规模 AI 小镇。
- 当前核心是“边境驿站压力锅”。
- 优先做最小可运行闭环。
- 不要让战斗系统压过 AI 征召与记忆系统。
- 不要让 LLM 直接控制权威数值。
- 不要把游戏设计塞进 Prompt。
- 不要在脚本中硬编码 NPC 档案。
- 文档必须跟着代码更新。

## 已知风险

- 系统体量容易膨胀。
- LLM 调用容易爆成本。
- NPC 自主计划容易不可控。
- Godot 场景结构如果不维护，会很快混乱。
- 记忆系统如果不压缩，会迅速撑爆上下文。
- 战斗如果做得太深，会拖慢核心 AI 玩法。

## 防错策略

- 每次只实现一个模块。
- 每个模块都先做最小版本。
- 新增文件必须更新 `MODULE_INDEX.md`。
- 新增设计必须更新对应模块文档。
- 任何大改前先阅读 `CURRENT_STATE.md`。
