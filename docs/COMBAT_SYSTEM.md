# COMBAT_SYSTEM.md

## 战斗目标

战斗系统用于制造外部压力。  
它不是项目的唯一核心，真正的核心是战前动员、战中崩溃、战后记忆反噬。

战斗中的时间相关数值使用 TimeSystem 的有效逻辑时间倍率结算。攻击间隔、持续伤害、恢复、建筑受损等不读取真实帧率作为权威速度，也不通过 Godot 全局时间缩放实现。玩家加速时战斗数值同步加快；LLM 战斗判定等待返回时，战斗数值随逻辑时间减缓。

## 战斗触发

两种触发方式：

1. 玩家手动摇响警铃。
2. 敌人开始攻击城门/围墙或攻入驿站。

方式 1 触发后，入伍且有武器的 NPC 尝试在门口集结。  
方式 2 触发，或单位在一定范围内遭遇敌军时，放弃集结，直接执行战斗策略。

## 兵种判定

兵种由装备和坐骑决定：

| 装备组合 | 实际兵种 |
|---|---|
| 剑盾 | 近战步兵 |
| 长杆武器 | 长杆步兵 |
| 弓 | 弓箭兵 |
| 弩 | 弩兵 |
| 近战武器 + 马 | 近战骑兵 |
| 远程武器 + 马 | 骑射单位 |
| 无武器 | 非战斗人员 / 避战单位 |

## 战斗前 LLM 判定

战斗触发时，全员进行一次心理判定。

入伍 NPC 可选择：

- 参战
- 逃离驿站
- 斗志激昂

非入伍 NPC 可选择：

- 尽可能避战但不离开驿站
- 逃离驿站

判定等待期间，Godot 侧需要向 TimeSystem 申请 LLM 慢速；判定返回、失败或规则降级后释放，避免战斗在模型返回前大幅推进。

战斗前判定必须包含该 NPC 当前 `current_order`。守备官可以在指令中要求守门、护送、避开前线等，但该文本只影响 NPC 的主观判断，不能直接强制判定结果，也不能绕过入伍状态、装备、HP 或战斗规则。

## 低血量判定

当单位 HP 低于 30% 时，触发一次 LLM 判定。

可能结果：

- 继续参战
- 逃离驿站
- 斗志激昂

低血量判定同样需要申请 TimeSystem 慢速，且每名 NPC 每波最多触发一次。

低血量与逃离相关判定也必须继续携带最新 `current_order`，让 NPC 在受伤或恐惧时重新解释守备官要求，而不是把发布指令时的旧判断当成永久结果。

## 昏迷机制

NPC 不死亡。  
HP 清零后在原地倒下并进入昏迷。

规则：

- 昏迷 NPC 不能移动、工作、战斗、对话或执行计划。
- 昏迷 NPC 不接收地点/广场公开广播或状态见闻，见闻库暂停更新。
- 昏迷 NPC 会极慢自然恢复 HP。
- 其他NPC可治疗昏迷 NPC，使其更快恢复。
- HP 恢复到 30% 后复苏。
- 复苏后重新评估计划。
- 如果仍在战斗中，复苏后重新进行战斗心理判定。

当前 T0501/T0502/T0502A/T0503 已实现 HP 扣除、昏迷状态、自然恢复、协助治疗、自动复苏和昏迷见闻暂停的最小闭环：`NPCSystem.apply_damage_to_npc(...)` 是权威扣血入口，GM `attack_npc` / `damage_npc` 可触发调试扣血；HP 到 0 后 NPC 设置为昏迷、停止移动并阻断行动。系统会写入 `damage_taken` 和 `unconscious_started` 结构化事件，昏迷事件按当前信息地点 `local_public` 广播给同地点 NPC。昏迷 NPC 会随 `TimeSystem.logical_time_tick` 以每游戏小时 2 HP 的速度自然恢复；其他可行动 NPC 可协助治疗，治疗按医术熟练度增加恢复速度并按逻辑时间消耗第纳尔，每个昏迷目标最多 2 名治疗者。HP 达到 Max HP 的 30% 后自动复苏、回到 `idle`、重新允许行动，并写入 `revived` 本地公开事件。昏迷期间 NPC 不接收见闻广播，复苏后恢复接收。敌人攻击尚未实现。

## 战斗策略

### 剑盾/长杆步兵

- 主动进攻
- 避战

### 弓/弩步兵

- 最大化输出
- 保持距离射击
- 避战

### 近战骑兵

- 主动进攻
- 拉开距离冲击
- 避战

### 骑马远程

- 最大化输出
- 保持距离射击
- 避战

## 敌人 AI

Demo 阶段敌人使用规则 AI，不调用 LLM。

目标优先级：

1. 攻击城门/围墙
2. 攻击仓库
3. 攻击主厅
4. 如果一定范围内有我方单位，优先攻击我方单位

## 战场公开信息

战斗中关键事件必须先作为结构化事件写入 `MemorySystem`。每个事件关联 `subject_npc_id` 和 `location_id`；事件写入 NPC 自身事件库后，再按 `visibility` 发送到所在建筑的信息节点，由节点即时广播给当前在场 NPC；节点不保存事件历史。

通过信息节点公开广播的战斗事件包括：

- 敌我大致人数
- 某 NPC HP 低于 30%
- 某 NPC 击倒或击杀敌人
- 某 NPC 昏迷
- 某 NPC 被治疗
- 某 NPC 复苏
- 某 NPC 逃离
- 建筑受损

若战斗发生在可进入建筑内部，事件可以同时广播到该建筑信息节点；室外战斗、围墙/城门/主厅受损、敌袭开始和战斗结归入广场公开广播。

战斗结束后，NPC 回到工作状态，并根据自身经历重新评估计划。
