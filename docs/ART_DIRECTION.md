# ART_DIRECTION.md

> 本文件是《这不是我的战争》Demo 的美术方向合同。美术实现不得只追求单张截图漂亮，而应优先保证俯视角下的建筑、职业、行动、战斗和状态可读。

## T0135-P8AR4 食堂工作状态表现规范（2026-08-24）

- 每个权威灶台必须独立形成“灶火—锅内食物—锅上蒸汽—排烟罩—专属烟道—屋顶烟囱”的连续视觉链；不得以食堂整体有人为由同时点亮所有灶，也不得让多个灶共用一处无对应关系的烟。
- 烟囱筒身与顶部砖冠必须是四壁围合的真实中空结构，俯视能看到中央孔洞和内壁深度；禁止用黑色实心方块假装烟道口，外部加固铁箍也不得封死中心。
- 食堂 Lv.2 不在既有西 / 中烟囱上追加悬空雨帽、防火帽或无承重关系的盖板；烟囱口保持敞开中空，等级丰富度由室内收纳、备餐和燃料设施表达。
- 空锅 / 空灶保持冷暗。只有该灶实际有人加工餐食时，锅底出现低矮火焰和克制暖光，锅内出现俯视可读但不过度鲜艳的多色炖煮食材，蒸汽轻而浅，烟囱烟较深且从顶部出口开始。停止工作后可允许现有烟粒自然消散，但不得继续发射。
- 火焰、食材和烟雾只表达工作状态，不表达库存或完成进度；表现数量不得反向改变粮食、餐食、效率、占用和升级规则。

## T0135-P8AR3 铁匠铺结构、工位与炉火规范（2026-08-24）

- 边境铁匠铺采用“后部砌体炉区＋前部有顶通风锻造棚”，不能再读成四面封闭民房。低坡冷灰蓝屋顶保留职业辨识，后墙 / 后侧墙承担防火排烟，前侧以落地木柱、横梁、低栏和可关闭入口形成开放工作面；可见壳体与碰撞必须一致。
- 炉口必须面对铁砧和工作区，烟罩—烟道—烟囱—出口保持同轴。铁砧必须由石脚 / 木墩实际承到地面，热铁贴合砧面，托板、架子和灯必须能追溯到腿、墙或横梁；禁止以“装饰漂浮”代替结构。
- NPC 锤击距离以动作落点可读和实体净空同时成立为准。当前铁砧中心—站位中心为 `1.10 m`；不能为了手贴上去让胶囊穿入铁砧，也不能退到锤子打空气。
- 炉火是工作状态反馈，不是常驻环境特效。只有实际占用锻造位并执行打铁时，炉膛热光、火焰、火星、烟、风箱和对应热铁共同启动；停止工作必须共同熄灭。夜间实体灯按 `2→3→4` 随工位 / 服务区扩建增加，日间后炉区以受墙体遮挡的冷日光补足可读度。
- 灯具支撑必须在屋顶透明后仍能解释受力，同时不得为灯额外侵占作业净空。铁匠铺四盏工作灯统一挂在砌体内墙，只使用可见背板、短挑臂和斜撑；禁止专用落地柱、跨工位棚架、局部门架，也禁止只有灯和短杆悬在空间。任何依赖屋顶梁的吊链 / 吊钩必须与承重梁共同透明。中央门路不摆磨轮、箱柜或非入口设施，精加工设备放到侧边服务区。

## T0135-P8AR2 露天灯具升级与远景可读规范（2026-08-24）

- 菜园、训练场和马厩最高级使用四点照明，但一级不得提前达到满级通明：三级数量固定为 `2 → 3 → 4`。一级两盏贴近初始工位，二级第三盏服务扩建功能区，三级第四盏随最终新工位出现。
- 灯具、支撑、火芯和光池必须同级出现；禁止隐藏未来灯柱却保留不可解释的地面光池，也禁止只显示灯模而没有夜间照明。二级没有新增容量的菜园 / 马厩，用灌溉、饲料或维护服务区解释第三盏灯，不伪造工位。
- 玩家允许的最大拉远镜头仍要读到夜间灯火。可以在后续性能任务中降低远景阴影精度，但不得按镜头距离熄灭灯芯、光源或改变建筑的夜间 / 占用启灯事实。

## T0135-P8AR 露天工作灯与安装规范（2026-08-24）

- 没有 P7R4 室内基础补光的菜园、训练场和马厩不能沿用“一处一盏小墙灯”的室内配置。最高级使用四点边界照明，光线从两侧交叉覆盖真实田畦、训练位或马栏；低等级按 P8AR2 逐级解锁，夜间有人时达到对应规模的工作可读度，但场外仍保留夜色。
- 露天灯必须有高于围栏的实体木柱、铁帽和横臂，或确实挂在现有棚柱上；成对灯臂朝向场内。封闭建筑墙灯必须有背板并与墙面法线一致，禁止仅靠局部坐标把灯悬在透明空间。
- 主厅等不可进入建筑的常亮灯必须在默认俯视镜头中同时读到灯体、安装结构和入口光池。灯柱可作为门廊构件，但不得扩大建筑包络、堵塞道路、公告牌或塔防平台。

## T0135-P8A 实体功能灯规范（2026-08-24）

- 灯具必须先作为可信建筑构件成立，再作为光源工作：封闭建筑放在梁下、工位旁或门廊，露天建筑放在棚下 / 围栏柱，守备结构放在入口和巡逻面。优先复用同一 Quaternius 灯笼，新增墙灯必须有可读铁托；禁止悬空、穿墙、堵门或侵入 NPC 工位。
- 灯罩与支架全天可见；只有发光核心和局部光在 `18:00–06:00` 按建筑规则启用。主厅、仓库、围墙和前后门夜间常亮；其他建筑有 NPC 才亮；宿舍必须有人醒着才亮。关闭状态不得残留发光球或自发光火芯。
- 功能灯用暖色、克制范围和实体阴影表达“有人在夜间使用空间”，不得把整个建筑或室外地面染成发光盒。P7R4 的宽域环境填光仍承担室内基础可读度；功能灯只增加有明确灯具来源的局部层次并关闭体积雾贡献。中远景可以降低阴影精度，但灯芯和实际照明不得随镜头距离淡出。

## T0135-P5 全图自然散布规范（2026-08-24）

- 自然细节必须按地形语义分区：河岸读湿草 / 蕨 / 卵石，山脚读苔藓 / 冷灰岩 / 贴地灌木，林下读深色蕨与矮灌木，道路边缘读断续草侵入与碎石，城内空地读被踩踏环境中的少量短草与石屑。不得把同一组素材按均匀概率铺满地图。
- 地表过渡不得形成闭合装饰圈、等宽边框或规则椭圆。河岸使用随河槽横截面变化的渐隐湿带；山脚使用错位的不规则苔藓片；道路只在泥肩外缘出现断续土色和草，不描整条道路轮廓。
- 程序草使用锥叶三角簇，蕨使用五向低模叶组，灌木与岩石保持粗壮可读轮廓；色彩只在深绿、灰绿、湿褐和冷灰的相邻低饱和区间变化。草叶 / 蕨叶为双面无影材质，禁止出现远景黑片。
- 装饰密度不能牺牲功能阅读：河槽、道路核心、建筑最高级包络、真实入口、广场集结中心、公告牌、敌 / 商 / 逃路线与器械射线必须留白；所有本阶段细节无碰撞、导航、点击与权威状态。

T0132-P6 冻结公告牌正式基线：公告牌必须位于主厅正门旁并读成附属公共设施，而非广场中央建筑或悬浮 UI。轮廓采用两根落地木柱、可信横撑、带框告示面和有承托的闭合小屋顶；近景至少可辨多张错落纸页、固定钉、封蜡与守备徽记。木、灰褐瓦和石脚与主厅材质语言一致。公告牌保持非建筑、无 HP / 等级 / 工位；点击热点可以存在，但不得以实体碰撞阻断主门和支路。

T0132-P5 冻结正式道路主体基线：道路必须保持 `station_layout_v2` 已批准的不规则端点、宽度与用途分类，以低饱和压实泥土而非亮色石板或纯色矩形表现。每段至少具有较软的不规则泥肩、较实的路芯和断续车辙；碎石只作稀疏边缘破形，交汇点使用同色圆钝泥地收口。道路只属于表现层，不得生成碰撞、NavigationRegion、点击遮挡或寻路权重；敌我单位可以跨越道路并继续选择最短可行路线。

T0132-P4b/P4bR 冻结正式箭塔基线：箭塔应读成架设在木制寨墙 / 主厅承台上的紧凑速射木塔，而不是拉长的房屋、纯盒子哨塔或缩小弩床。远景依靠四柱塔架、交叉撑、抬高射击层和独立灰褐瓦顶识别，近景必须看见低护板、储箭架、转台、箭槽、弩弓、弦和回位轮。双坡顶必须外檐低、中央屋脊高，屋脊梁与瓦面交线贴合；禁止中央凹陷的蝶形屋顶或悬空屋脊。塔体最高包络不得超出两类 `3.6 m` 平台；不得伪造没有玩法权威的操作员。待机必须有一支装填箭，发射后箭槽短暂为空并出现可见飞行箭，回位完成后才补入下一支。主厅平台与围墙平台统一为深色 WoodTrim 木构，但主厅保留四个既有坐标、解锁等级和安装高度。

T0132-P4a 冻结正式弩床基线：它应读成安装在寨墙 / 主厅防御台上的重型扭力弩，而不是三根盒体拼成的玩具弩，也不能大到越过 `3.6 m` 平台护栏。远景轮廓依靠宽弩臂、中央重箭、双轮车架和后置绞盘识别；近景必须看见承重梁、转台、扭力盒 / 铁箍、弓弦、止轮木与装填槽。木料和铁件沿用 Quaternius 驿站材质，避免光滑塑料或纯灰金属柱。待机有一支床面箭，发射后箭槽明确为空，绞盘和弓弦完成重装后下一支箭才出现；飞行弹体必须比普通手持箭更粗、更长，从弩床口沿目标方向射出。

T0132-P2/P2R/P2R2 冻结仓库“边境商路加固货栈而非透明货架棚 / 锯齿厂房”的辨识基线：远景依靠单一连续深色瓦屋顶、一条主屋脊、石质装卸台、前檐雨棚、屋脊吊运架与后部挑高安全仓识别；近景必须看到封闭砖石 / 灰泥 / 木构实体、宽双扇货门、吊钩、车辙、侧仓和分类物资。仓库不可进入，因此屋顶与外墙始终不透明。主仓、侧仓和高仓必须保留原生瓦片纹理，但统一使用低饱和烟熏灰褐色，禁止鲜艳新木 / 橙瓦抢过旧木立面。Lv.1 / 2 / 3 分类储藏保持 `5→6→7`；货物只表达类别，禁止按实时库存数量增减模型；禁止再次重复已经包含完整双坡与屋脊的屋顶模块。

T0132-P1/P1R/P1R2/P1R3/P1R4/P1R5 冻结主厅“边境指挥核心而非宫殿 / 普通民居”的辨识基线：远景依靠全站最大体量、封闭低层石木指挥体、连续城防屋面、女儿墙 / 垛口、紧凑中央指挥屋、酒红旗帜和盾徽识别。禁止纯色淡蓝 / 白色长方体主体、薄墙空壳和互相穿插的超大屋顶。升级构件同样必须遵守真实建筑语义：Lv.2 扶壁不得遮挡门窗，须从墙基接到明确受力部位；Lv.4 使用一面与屋脊石座、铁箍和绳结真实连接的酒红燕尾守备旗，禁止无意义方块，也禁止任何火盆、发光球或警灯轮廓；Lv.6 门楼塔必须同时具备实体墙身、原生贴图立面、木构和与主厅同色的瓦顶，不允许鲜艳悬浮阁楼。四个 `3.6 × 3.6 m` 器械平台上方必须无遮挡、底部必须与承重屋面连接，部署模型落在可见器械座上。主厅不可进入，不随近景透明。

T0131-P9/P9R 冻结马厩“露天边境马院而非封闭谷仓”的辨识基线：远景依靠成排开放马栏、宽牵马门、中央夯土通道、马头 / 马蹄标识、草料和鞍具识别；近景补足清扫、洗刷、饮水、干草、修蹄、恢复和后勤。两侧连续顶棚必须从外墙覆盖到马栏内沿，完整遮蔽每个马匹锚点的马体净空，而不是只形成贴墙窄檐。Lv.2 只能扩充共享维护 / 饲喂设施，禁止提前摆第三照料位；Lv.3 才同步出现第三照料栏和产驹 / 恢复配套。场内只显示 HorseSystem 的真实马，围栏 / 马栏 / 马匹常显，仅顶棚近景淡出。

T0131-P7 冻结菜园“露天实用生产区而非方盒建筑”的辨识基线：远景依靠深色成组田畦、低石基木篱、宽园门、沿边农具棚与稻草人识别；近景必须能读到种子、浇水、灌溉、堆肥、农具、收获与分拣。Lv.2 只能用水源、灌溉和育苗表达效率，禁止提前摆第三块完整田畦；Lv.3 的第三田畦、灌溉支路和田边辅助设施必须同级出现。露天区域始终优先点选内部 NPC，只淡出会遮挡视线的小棚顶，不淡出围栏和地块边界。

## 1. 目标风格

- 建筑、室内道具与环境主要资产家族：Quaternius 低多边形系列；角色允许使用独立但经色板、材质和比例适配的统一迷你人形家族。
- 目标观感：俯视角、玩具感、粗壮比例、低多边形、中世纪晚期 / 文艺复兴早期边境驿站。
- 参考重点：吸收《奔奔王国》式的建筑轮廓与室内可读性，以及《人类一败涂地》式的简化肢体和物理反馈；不复制具体角色、建筑或 UI。
- 核心关键词：`清楚`、`有生活`、`有压力`、`可观察`、`不过度写实`。

## 2. 统一视觉语言

- 使用有限而统一的色板，材质以哑光、轻微磨损和柔和高光为主。
- 头、手、工具和职业道具可以适当放大，确保高机位下仍能识别。
- 建筑依靠屋顶、烟囱、门窗、招牌、室内功能道具和升级增量区分，不依赖 `Label3D` 才能辨认。
- 环境保持“边境压力锅”而不是整洁童话小镇：允许修补木板、泥地、车辙、草垛、物资堆和战损痕迹。
- 核心角色、核心建筑和主要环境不得混用明显不同作者、比例或材质语言的资产；外部资产必须先经过比例、色板和材质适配。

### 2.1 T0125 已确认基线

- 比例：`1 unit = 1 m`，角色正面 `-Z`、向上 `+Y`；普通人形参考 1.82 m，建筑使用 2 m 模块与约 3.125 m 层高。
- 色板：泥灰绿地面、暖灰泥墙、深褐木料、暗红褐屋顶、冷灰金属、暖金选中和浅蓝角色边缘光；精确值由 `art_scale_baseline.json` 统一提供。
- 材质：哑光粗糙表面为主，贴图生成 mipmap、Godot 导入上限 2K，运行时使用 anisotropic 过滤；方向光阴影默认开启。
- 继承：Quaternius 导入场景只读，项目包装层使用 surface override / overlay 完成色板、rim 和选中 outline，不直接编辑导入缓存。
- 六包最小样本、性能和已知源数据告警见 `docs/ART_BASELINE.md`；本基线不代表建筑碰撞、室内、角色装配或正式 UI 已完成。

## 3. 镜头与屋顶透明

- 镜头拉远时，所有建筑显示完整不透明屋顶，维持驿站整体轮廓。
- 镜头拉近时，屋顶在两个配置阈值之间平滑降低透明度，露出室内；不得突然开关或闪烁。
- 透明值由统一的相机缩放快照驱动，不由每座建筑分别读取输入。
- 屋顶透明只属于表现层：不改变墙体碰撞、导航、建筑点击、HP、升级、工位、事件或见闻。
- 屋顶透明期间需要同步处理阴影，避免透明屋顶仍投下完全不透明的实心阴影。
- 近景室内必须有足够环境光和局部功能光，不能因屋顶淡出后仍是一团黑。
- 屋顶 / 外墙淡出只改变主画面可见 alpha，不取消建筑实体阴影；太阳和月亮仍应投出完整壳体轮廓。室内可读依靠克制补光解决，禁止用关闭屋顶阴影制造不真实的露天采光。

T0126 实测基线：全局归一化范围为 `18–42 m`；首个 4 × 4 m 建筑使用 `20–30 m / 最低 0.06`，对照建筑使用 `23–34 m / 最低 0.12`。区间内采用 smoothstep，alpha 低于 `0.98` 时关闭屋顶 cast shadow。该数值是可按建筑覆盖的起点，不是所有尺寸建筑必须复用的硬编码。

## 4. 建筑最低标准

每座正式建筑至少满足：

- 外部轮廓能表达用途。
- 可进入建筑拥有真实地板、墙、门、室内家具、碰撞、导航区域和功能位置 Marker。
- 可进入建筑的正门必须保留至少 `1.8 m × 2.2 m` 实体通行净口，门中心不得布置立柱、招牌支脚或家具；双扇门读取真实 actor 接近自动开、清空后延迟关。门叶默认是跟随外墙透明的无碰撞表现，通行继续由正式静态碰撞和 NavigationMesh 决定，避免出现第二套门禁权威。
- 功能位置的视觉数量与 `building_defs.json` 权威配置一致。
- 建筑升级产生可见部件变化，例如新增工作台、病床、储物架、烟囱、加固墙体或器械平台；不能只改变数字。
- 受损、修复中、升级中和摧毁状态有可见反馈，但表现层不拥有权威状态。
- 屋顶、外墙、室内、升级部件、碰撞和特效挂点彼此分层，可独立控制。
- 每座建筑从 Lv.1 起必须保留最高等级所需的完整地块；未建成区域可以显示地基、材料和封闭扩建区，但不能被道路、邻楼或装饰占用。
- 每个权威功能位置必须同时具有可辨认设备 / 家具、同 ID Marker、NPC 实际站位 / 朝向和占用状态。只提高 HP / 效率的等级不得摆出假工位；增加容量的等级必须同步增加实体、Marker、碰撞、导航净空和动作位置。
- 正式功能家具执行“资产主体优先”：Quaternius 已有合适床、桌、椅、长凳、工作台、容器或职业道具时，必须先以导入资产建立主体轮廓和材质语言；程序 Box / Cylinder 只用于墙体、台阶、包边、导轨、碰撞代理与少量缺失装饰，不能把完整家具或核心陈设重新画成粗糙几何占位。确无合适资产时，先登记缺口并单建筑评审，禁止一次批量生成多个未经近景检查的替代模型。

全站米制坐标、最大等级地块、功能位置单元、道路、自然边界、敌人入场和镜头规格统一见 `docs/SCENE_SPACE_AND_VISUAL_PLAN.md`。后续建筑美术不得脱离该文档单独决定占地。

A3b9R 教堂是首个返工样板：五排左右 Quaternius 木长凳围绕连续中央通道布置，十个实际祈祷席以单席座垫和书本提示一一可读；圣坛具有抬高地台、十字架、烛台、圣杯和读经台，Lv.2 屋架移到圣坛上方而不遮挡中殿。该样板冻结“先判断真实功能布局，再选资产，再补结构与碰撞”的制作顺序。

A3b10R 工械坊延续单建筑返工：不再用三张同质程序桌代表全部工程工作，而让两张 Lv.1 工作台分别以弓材 / 虎钳和齿轮 / 零件盘表达制弓与机构装配，Lv.3 第三台以弩床式床身、弓臂和绞盘表达攻城器械总装。共享工具墙、吊架、制图测量台和材料架使用同一 Quaternius 木料 / 金属语言，但不出现可误认的新工位。近景判断标准是“不看标签也能区分三种工作”，俯视判断标准是“每张可用桌仍对应唯一 NPC 站位”。

T0131-P1 将上述家具返工提升为完整工械坊建筑。主体使用 `12 × 12 m` 方正作坊壳而非民居小屋：冷灰墙面、深木框架、低坡冷灰蓝圆瓦屋面和屋脊低矮采光通风监楼形成工程建筑轮廓；内部中央装配通道必须从门口贯通，订单图板、木铁坯料、零件箱、油桶、工具与照明用于增加生活化密度，但不能构成第四张可误认工作台。拉近时屋顶和四周墙体同时淡出，室内各区从俯视角仍须可读。

T0131-P1R 经用户验收后成为后续逐建筑制作的最低表现密度：主体壳、职业家具、非工位杂物、逐级附属设施和近景透明链都必须完整，但不能复制同一个作坊模板。每座建筑还必须用不同的主体轮廓、屋面节奏、主材 / 强调色、入口构图、室内功能分区和升级新增物维持辨识度；不看名称标签时，玩家仍应能区分用途。

T0131-P1D 冻结可进入建筑的门交付合同：铁匠铺 / 工械坊首批使用 `2.08 m × 2.35 m` 净口和向外折开的双扇厚木门；碰撞层 2 的 NPC / 敌对实体进入门内外感应区即开门，离开后短暂留门再关闭。门框可以随建筑职业配色变化，但不得用门中央立柱、过厚门框或装饰重新压缩净口；门扇、门框和附着装饰必须进入建筑外墙透明链。

T0131-P3R 冻结小诊所“治愈但仍是边境医舍”的辨识基线：不得再复制工械坊的方正双坡瓦顶轮廓，主体采用宽缓鼠尾草绿四坡屋面、短屋脊与中央玻璃采光气楼；暖象牙灰泥、鼠尾草绿木构 / 百叶、奶油色布艺和柔和药草绿形成洁净安静的主关系，陶金 / 暖花色只作小面积焦点。正门以不挡净口的护理雨棚、两侧药草花箱和叶片药臼徽记表达用途，不使用现代红十字、霓虹医疗色或过度甜美的糖果屋色板。远景首先靠四坡剪影和采光气楼识别，近景再靠药房窗、药草和布艺补充语义；所有气楼、雨棚、百叶、花箱与升级通风件须随外壳统一透明。

T0131-P4 冻结食堂“边境公共饭堂而非民居 / 诊所”的辨识基线：主体采用更宽的横向体量、低缓陶瓦屋顶、后厨成组烟囱、暖赭灰泥与深橡木框架，炉火 / 暖灯只作局部视觉焦点。远景依靠宽屋面和烟囱组识别，近景依靠厚木公共餐桌、炖锅后厨、汤勺餐盘徽记、储粮 / 餐具 / 洗涤 / 柴薪陈设表达用途。Lv.2 只通过收纳、备餐和燃料设施表达效率，不在已有烟囱上堆悬浮盖件；Lv.3 才以第三灶—第三罩—第三烟囱的完整链表达容量。桌上食物不得冒充实时库存，所有烟囱、棚体和升级附件须与外壳统一透明。

T0131-P5 冻结宿舍“边境集体长屋而非民居 / 客栈”的辨识基线：以五段重复床位窗、低缓深酒红长屋顶、五个低矮通风帽和月牙枕头徽记表达集中住宿；近景必须一眼看到两列五排十张床及十套个人脚箱 / 挂衣，而不是用模糊床铺堆叠暗示容量。Lv.2 只以壁炉烟道、保温、修补、窗板和布草表达更温暖耐用，禁止出现第十一张床；所有烟道、顶梁和外墙升级附件须与外壳统一透明。

P8AR5 冻结公共盥洗设施语言：宿舍和诊所使用壁靠式木石盥洗架，必须读到接地支脚、承托台、凹盆 / 水面、墙背板、架高储水罐、短出水嘴和毛巾，不能只摆一个桶，也不能做成现代陶瓷洗手台。宿舍版本放在西端床列之间并靠近两排床的视觉中线，二级壁炉偏置到另一侧保持净空；诊所版本放在北墙两医生桌之间，配色分别服从宿舍深酒红木构与诊所鼠尾草 / 象牙体系。洗手池是生活语义装饰，不得伪装成新增工位或可结算水源。

P8AR6/P8AR6R 冻结宿舍卫生间的室外附属物语言：采用两间完全同规格、同朝向、紧邻并排的小型坑位，单间体量必须明显小于宿舍；以接地石基、暖灰泥墙、深木框、封闭拼板门、低缓深酒红双坡顶和通风构件读成边境驿站茅厕。门上的月牙只作低调识别符号，不使用现代 WC 标识、瓷砖、管道或明亮洁具。两间都没有可展示室内，屋顶与墙体始终保持实体不透明；并排缝只用于避免屋檐穿模，不增加围栏院落或新道路把它升级成独立功能建筑。

T0131-P6 冻结酒窖“半石砌发酵作坊而非酒馆 / 民房”的辨识基线：远景依靠低矮窖基、深酒红低坡顶、成组发酵通风帽及桶箍葡萄藤徽记；近景必须同时读到发酵桶、熟成储酒、冷却 / 管线、清洗排水、瓶装与制桶维护。Lv.2 只能用熟成、冷却、管线和加固表达效率，禁止提前摆第三套完整发酵设备；Lv.3 的第三发酵桶、支管和通风帽必须同级出现。酒瓶、粮袋和装卸货不得伪装成实时库存。

P6R 冻结酒窖储桶密度：Lv.1 后墙两角各使用“下二上一”的三桶木架，Lv.2 遮阴熟成区扩成五桶双层架，Lv.3 装卸区追加三桶出货组；装饰桶累计 `6→11→14`。桶堆必须靠墙 / 靠架形成承重关系并避开门路和桶外工作位，不能零散铺满地面；可见桶数只表达作坊规模，不代表实时酒库存或新增酿酒容量。

P4R 进一步冻结升级陈设的叠放规则：新增柜台不得为了“沿墙”而占用基础碗橱的同一段墙面。当前 Lv.2 / Lv.3 柜台改在正面墙左右横排，柜体、台面、面包 / 杯具必须作为整体移动；从俯视角需要读成连续的发餐边界，但中央入口至少保留正式门洞及转向净空。

升级视觉遵循“效率先强化、容量后扩张”：Lv.2 用工具测量墙、传动吊架、制图台、偏置收料架与滑轮吊臂表达更高效率 / 耐久，不增加工程席位；Lv.3 才增加弩床式总装台、主吊装梁、成品架和西侧有顶装配 / 装卸湾。附属棚使用低矮圆瓦棚、木平台、立柱斜撑、绞盘、绳具和周转箱形成真实用途，禁止退回一整块薄板加两根柱子的占位表达。运行验收数量固定为可见 fixture `3→6→7`、权威工程位 `2→2→3`，任何后续装饰都不得破坏这一对应关系；贴近屋顶的升级梁架必须与主屋顶同步渐隐。

A3b11R 主厅冻结“边境守备指挥厅而非宫殿”的造型基线：主体必须是全站最大但不依靠高耸尖顶，采用横向加固的灰蓝石质体量、模块化砖石门窗、中央门厅与低矮圆瓦屋顶；旗帜、壁灯、盾徽和四角防御平台提供指挥 / 城防识别。四个平台需从俯视角同时读出，并按 Lv.1 / 3 / 5 / 6 增长；Lv.2 / 4 / 6 的墙体、信号屋面、塔楼加固必须看得见但不能伪装成 NPC 工位或改变主厅不可进入规则。

A3b12R 仓库冻结“边境储备仓而非民房 / 空院”的造型基线：木网格加固墙、宽双开装卸门、雨棚 / 滑轮、坡屋顶和货运车先建立建筑用途；食品、木石铁、钱箱与装备再用不同容器轮廓分区。中央装卸通道必须保持开放，Lv.2 增加侧仓高架、Lv.3 增加挑高储藏翼，但都不生成 NPC 工位。分类货物只说明资源类别，不能用可见箱数冒充实时库存数量。仓库屋顶使用统一相机距离渐隐，近景透明时关闭实心阴影。

### 4.1 铁匠铺造型基线

- 铁匠铺不使用暖橙、高尖、宽大到压过主体的住宅式屋顶；当前候选采用收窄的低坡圆瓦轮廓，冷灰蓝屋面、灰紫外墙和蓝灰升级棚檐，让炉火继续作为唯一强暖色焦点。
- 炉膛贴后墙布置，烟囱平面中心必须和炉膛烟道对齐；烟囱底部从炉体上沿开始，顶部必须明显高于屋脊，不允许整段从地面穿过炉体。
- 低坡不等于完全平顶。远景仍要读出独立屋面与排烟轮廓，近景透明后则要保留炉膛、铁砧、工具和工作动作的清晰层级。
- 被否决的旧 `4 × 4 m` 室内只保留为进门、权威占位、动画和屋顶技术原型，不再是最终占地基线。正式版本使用 `16 × 16 m` 预留地块、约 `14 × 12 m` 房体，Lv.1 / 2 / 3 分别真实显示 `2 / 2 / 3` 个独立锻造湾。
- T0131-P1B 将两侧升级附属物统一为低于主屋面的贴墙斜棚：Lv.2 东侧是燃料 / 矿料棚，Lv.3 西侧是成品整理 / 装卸棚。两者都用石台、冷灰板岩、深木柱与斜撑形成可读结构，不能退回悬空薄板；最高包络必须留在 `16 × 16 m` 地块内，并与主屋面保持明确空气缝。
- 常驻烟囱是唯一允许有意穿过屋面的构件，必须从炉膛烟罩连续接到屋脊上方出口。贴近屋面的升级吊装梁 / 桁架属于屋顶附属结构，近景须与屋顶同步透明；吊链、吊钩和室内生产设备仍保留可见，避免透明后丢失工作语义。
- 室内吊灯、挂架和非烟道装饰必须按完整导入网格 AABB 留在主屋面最低点以下；当前铁匠铺吊灯至少保留 `0.1 m` 垂直净空，不能靠相机角度掩盖穿模。

## 5. NPC 与敌人最低标准

- 有头、身体、胳膊、腿、手、脚和基础面部；面部可以是抽象线条或简化眼睛 / 眉毛 / 嘴。
- 8 名 NPC 不看标签也能通过轮廓、主色、发型、服装和职业工具区分。
- 角色统一使用可重定向的人形骨骼和共享动画合同。
- 武器、盔甲、工具、坐骑和职业附件通过稳定挂点显示，并与程序权威槽位同步。
- 角色碰撞体用于导航和空间阻挡；伤害、HP、资源、行动成功与战斗结果继续由现有权威系统决定。
- 新角色目标为偏两头身的玩具化比例：头部约占视觉总高 `35–42%`，躯干短、四肢粗短、手脚与职业工具适度放大。这里约束的是轮廓比例，不要求角色在世界尺度上像儿童；试片应以约 `1.6–1.75 m` 的视觉总高与现有门、家具和点击尺度共同验收。
- 我方与敌方必须来自同一人物比例 / 骨骼语言；阵营差异优先使用服装剪影、盾牌 / 武器、主辅色和材质磨损，不用一方写实、一方卡通的混包方式区分。

### 5.1 T0128 首个正式角色基线

- 格伦使用 Quaternius 男性基础体、农民服装与短发；基础体自带简化眼睛 / 眉毛，正式外观不再使用胶囊 + 球体人物占位。
- 统一角色前向仍为 `-Z`，NPC 根坐标由程序移动；表现层只让骨骼模型朝向运动方向并按速度播放非 root-motion locomotion，不能用动画根位移改写路径。
- 固定装备挂点为 `RightHand / LeftHand / Back / Head / Body / Mount`。当前锤子使用项目内低多边形基础几何补足免费 Fantasy Props 没有铁匠锤的缺口，不伪称为第三方模型。
- UAL2 Standard 免费档缺少独立跑步、锻造和倒地动作；当前别名为加速 `Walk_Carry`、`Farm_Harvest` 和反播 `LayToIdle`。T0129 以实际画面判断替换优先级，不能因统一状态名存在就声称源动作已经齐备。

## 7. 战斗反馈最低标准

- 攻击动作有准备、命中和收势，不只让数值瞬间变化。
- 命中至少有声音、命中闪光 / 火星、短促受击动作和可选血液表现。
- NPC HP 清零表现为昏迷，不出现死亡文案或永久尸体。
- 布娃娃属于权威昏迷结果后的表现；复苏时需要可靠回到动画骨骼并播放起身。
- 建筑受击有碎屑、闪烁、裂痕或震动提示；器械攻击有发射、弹道或命中特效。
- 提供关闭血液的选项；关闭后战斗仍然清楚。

## 8. UI 最低标准

- 使用项目级 Godot `Theme`，统一面板、按钮、输入框、滚动条、Tooltip、进度条和弹窗。
- 风格基调为木、铁、羊皮纸与边境守备，不再使用纯线框作为正式 UI。
- 资源、装备、职业、建筑、状态、速度、警铃、虔诚和战斗信息使用同一套图标语言。
- 8 名 NPC 使用统一风格头像或从正式 3D 模型渲染头像。
- 正常、悬停、按下、禁用、成功、警告、受伤和战斗状态有一致反馈。
- GM 面板保持开发工具外观，不伪装成正式游戏 UI。

## 9. 环境与氛围最低标准

- 全站与外围使用同一套低饱和深绿色草地主色；不得用明亮浅绿内场对深绿外围制造“治愈草坪”或人工园林分区。泥地、道路和建筑基础仍可通过材质变化区分。
- 使用树木、岩石、篱笆、木箱、草垛、车辙、旗帜、火把、炊烟和物资堆填充空白，但不能妨碍导航与点击。
- 灯光和色彩必须保证远景读布局、近景读行动；夜间不能依赖调试标签找人。
- 音效覆盖 UI、脚步、工作、武器、命中、建筑、警铃、火焰、环境和结算。
- 场景边缘由河流、陡岸、岩脊、密林、悬崖和雾形成可信的不可通行自然环；自然物必须从驿站外围持续蔓延到地块边缘和镜头外，不能只摆一圈装饰带后露出空底。空气墙只作兜底。正门方向必须保留敌人从林中显现的进攻廊道，后门方向必须保留商人和逃离使用的峡口。
- 驿站布局禁止中轴对称、棋盘路网、等距排列和大面积中心广场。建筑位置应错位并沿弯折主路自然生长，但建筑正面只允许北、东北、东、东南、南、西南、西、西北八个方向，不能用任意小角度制造杂乱；公共空地拆为多个小型泥地节点，整体读作多次扩建的边境据点。
- 墙内保留约 `20–25%` 草地 / 泥地和构图留白，但留白应分散在建筑缝隙与小节点，不能集中成“皇宫前庭”。树木和巨石按实际 AABB、碰撞代理和道路退距布置，不以装饰穿插导航区。

### 9.1 T0135 自然场景生产基线

自然环境采用四类内容协作，不用单一手段包办：

| 内容类型 | 主要职责 | 本项目做法 |
|---|---|---|
| 低模实体模型 | 远景轮廓、真实遮挡、可接触体积 | 地形台阶、河岸 / 崖壁、山体、树干 / 树冠、巨石、篱笆、箱桶、草垛和火把结构；优先使用 Quaternius，同风格缺口才自制模块 |
| 材质 / Shader / 贴花网格 | 大面积表面变化与接触细节 | 深草、泥地、湿痕、道路羽化、车辙、苔藓、河水流动 / 岸边泡沫；不得用一张大照片或明亮草坪矩形覆盖全图 |
| 粒子 / 局部雾 | 会动、会消散的空气层 | 炊烟、炉烟、火焰、火星、尘土、落叶和边缘低雾；这些只负责气氛，不替代山、树或地形遮蔽 |
| 数据驱动散布 | 密度、节奏、变化和性能 | 树 / 岩 / 草按确定性 seed、分区密度、道路 / 门 / 工位 / 敌路排除蒙版散布；大量重复物使用分块 MultiMesh，近中远层分别控制碰撞与阴影 |

AI 图像只允许用于气氛概念、色板、图标、贴花或材质草案；需要占地、碰撞、导航、视线遮蔽或镜头边界的自然主体必须是可审计的 3D 几何。自然场景与建筑保持同一精细度的关键不是给每片叶子加面数，而是同时具备三层阅读：远景有河谷 / 山脉 / 林冠的连续大轮廓，中景有树群 / 岩群 / 河岸台阶 / 篱笆的结构，近景有草簇 / 卵石 / 根部 / 车辙 / 杂物和动态烟雾。

地面基色继续使用低饱和深绿体系，允许用相邻深浅和灰褐泥色建立斑驳，但不得回到城内浅绿、外围深绿的人工分区。山体、河岸和密林必须从可玩区边缘继续填到地图承底与镜头外；物理边界只决定“不能走”，可见美术负责解释“为什么不能走”，两者不得再次共用一排程序盒体。

灯光采用固定季节的连续天体循环，而不是到点硬切四套滤镜。太阳从地图东侧 `+X` 升起，经南侧天空 `-Z` 到达最高点，再从西侧 `-X` 落下；首轮采用 `05:30` 日出、`12:30` 最高约 `52°`、`19:30` 日落。月亮使用约 12 小时错相的独立东升西落轨道，采用 `18:30` 月升、`00:30` 最高约 `42°`、`06:30` 月落。太阳 / 月亮高度角连续驱动方向光朝向、能量、色温、阴影长度、天空、环境光、雾色与功能灯权重；白昼、黄金时段、暮光和夜晚只作调色锚点。任意时刻最多一套天体硬阴影占主导，避免双重影子。

`WorldEnvironment` 统一控制天空 / 背景、环境光、色调、深度 / 高度雾和后处理。低配基线使用所有渲染器可用的传统雾，Forward+ 高档才增加河谷、林缘和山脚的少量局部体积雾。实体灯的最终启停窗口按 P8A 用户定案固定为 `18:00–06:00`，并进一步服从建筑占用规则；天空、环境光和室内日光填光仍连续渐变。近景屋顶 / 外墙透明时，室内使用克制的环境填光和少量暖色实体功能灯保持 NPC、工位与动作可读，不依赖关闭全场阴影或把室内整体提亮成白盒。环境表现只读游戏绝对时间，暂停时冻结，倍速时同步加速，读档和 GM 跳时刻后直接按绝对时间重算，不能累计角度产生漂移。

T0135-P7R3/R4 冻结室内色温与光型规则：日间环境填光必须跟随同一太阳色与天空环境色，正午读作低饱和自然日光，清晨 / 黄昏连续过渡，只有夜间功能光明显偏暖。低配实时实现为每座封闭建筑一盏位于屋檐下、中央、宽角、低衰减且开启阴影的 SpotLight；opaque shadows-only 屋顶 / 外墙必须像遮挡日光一样遮挡室内光，镜头透明不得取消遮光，只有真实门洞允许窄幅自然溢光。地板不得读出离散圆形灯池或光源点；实际火把、灯笼和炉火局部光仍由 P8 单独表达。

T0135-P1R 冻结返修后的正式地表禁则：规划地块只能保存尺寸合同，不能渲染为建筑下方矩形色块；广场只通过道路自然拓宽来阅读，禁止额外绘制圆形、多环、星形、放射尖角或其他“地点徽记”。门前不再机械复制独立磨损贴片，入口由道路泥肩自然接门。卵石只能形成少量非闭合杂物簇，植被必须成簇且保持正常透明 / 背面表现，不能均匀撒点或出现黑色碎片。

T0135-P1R2 冻结城内生活密度规则：草、三叶草和碎石使用尺度、朝向、半径均不一致的小群落，允许在建筑之间形成疏密变化，但必须避开道路核心、门口和广场集结中心。箱桶、麻袋、绳索、长凳和器械不得全图随机撒点，必须按“装卸 / 畜养 / 供水 / 酒运 / 工艺材料 / 候诊 / 收获 / 训练”等功能靠近对应建筑的侧后勤区组织；远景读成生活痕迹，近景能解释用途，且不与室内陈设重叠。

T0135-P2 冻结河谷拓扑规则：河槽与水面分别控制中心、宽度和弯折，允许水流在更宽河槽内左右偏移，禁止两岸机械平行。高地、草坡、裸土肩、湿石岸和水面必须形成可读高差，且东西岸永不由地表三角形跨接。旧森林底板不得横过河水；P5 的河岸植被与岩群只能沿本拓扑追加，不能用散布掩盖错误地形。

T0135-P3 冻结东侧山脉拓扑规则：可见山体必须由 `X[120,175]` 近层山脚、`X[165,255]` 中层叠岩和 `X[235,350+]` 远层山脊共同解释边界，并连续越过南北地图边缘。三层使用错位截面与相邻冷灰色阶形成远中近关系，禁止恢复单条 RidgeMass 盒或用一排岩石冒充整座山；P4/P5 松林和山脚植被只能追加到该主体，不能另建冲突地形或逐件中远层碰撞。

T0135-P4R 冻结密林规则：正式边境树林统一使用高瘦松、标准层叠松和宽冠冷杉三种圆锥低多边形轮廓，不再混入高细节阔叶叶簇；差异只来自层数、宽高比例、尺度、朝向和相邻冷绿色阶。树林必须包围驿站全周，禁止前后矩形之间出现横向空带。树干按围墙距离从近疏到远密，河槽无树、河岸稀疏、山体显著稀疏；同时继续排除敌路、商路、逃离路和出生净空，路线两侧林幕遮住出生瞬间。逐树碰撞仍禁止，实体边界继续使用既有复合 StaticBody。

## T0132-P3 城防视觉语言

- 城防必须读成临时扩建的边境木栅寨墙，而不是石砌城堡：连续木板墙身、粗木立柱、双面横向束梁、斜撑、内侧巡逻道和木制垛口构成主轮廓；深铁件只作加固，石材只允许成为贴地防潮基脚。禁止连续石墙、石压顶、石塔身和简单染棕的无结构盒体。
- 正门是驿站主防御识别点：更宽更高的双木制守卫塔、外露角柱 / 交叉撑、守备色旗帜和重型包铁门；后门是克制的木制商旅侧门：低矮塔架、木牌、较少礼仪装饰。两门共用木构语言但不得同尺寸复制。
- 器械台必须先服从正式槽位和器械净空，再以木承台、支柱和斜撑与门楼 / 墙体形成承重关系；无槽位等级只做加固 / 测距语义，禁止用空台子制造虚假容量。
- 围墙槽位必须由正门左右的连续墙段承托，不能侵入门洞、骑在门楣上或由守卫塔承重。中央两台也必须与门塔外缘保留可读缝隙，使玩家一眼区分“升级围墙解锁器械台”和“升级城门增加耐久”。
- 围墙升级禁止在墙外悬挂没有连接节点的灰色长柱、薄铁板、长方体压条或整块木盒扶壁。扩槽等级已经由新增实体平台表达；额外加固只有在能看出立柱—横梁—斜撑传力关系时才允许出现。
- 正门左右墙段角度不同，附件不得统一复制城门朝向。左侧平台 / 测距件 / 旗面沿 `north_west_a`，右侧沿靠铁匠铺的 `north_east`；附件长边必须与脚下墙顶切线平行，器械正面使用对应墙段朝外法线。
