# MEMORY_AND_INFO_SPACE.md

## 模块目标

记忆系统用于让 NPC 记住玩家行为、地点见闻、战斗事件和自身经历，并在后续计划、对话、征召、逃离、战斗判定中产生影响。

## 三层信息结构

### 1. Event Log

全局事件日志，记录发生过的重要事件。

包括：

- 玩家对话
- 给钱
- 给装备
- 指派任务
- 攻击 NPC
- NPC 工作
- NPC 吃饭/睡觉
- NPC 昏迷
- NPC 复苏
- NPC 逃离
- 战斗事件
- 建筑受损
- 资源变化

### 2. Location Info Space

每个地点拥有公共信息空间。

地点包括：

- 广场
- 主厅
- 宿舍
- 食堂
- 酒窖
- 菜园
- 铁匠铺
- 训练场
- 马厩
- 小教堂
- 小诊所
- 工械坊
- 仓库
- 围墙

NPC 进入地点时，会继承该地点近期重要信息到见闻库。

### 3. NPC Memory

每个 NPC 拥有：

- 当天短期记忆
- 知识图谱
- 第一人称日记

## 广场公开见闻

广场是公共信息中枢。部分重要事件即使不发生在广场，也会公开到广场信息空间，代表消息传播。

公开事件包括：

- 战斗开始与结束
- 敌我大致人数
- 某 NPC HP 低于 30%
- 某 NPC 击倒或击杀敌人
- 某 NPC 昏迷
- 某 NPC 被治疗
- 某 NPC 复苏
- 某 NPC 逃离或试图逃离
- 围墙、仓库、主厅受损
- 玩家在公共场合攻击、威胁、赠予 NPC

## 短期记忆

当天所有重要经历进入短期记忆。  
当天 LLM 调用时可以参考短期记忆。

短期记忆内容包括：

- 今天做了什么
- 做了多久
- 产出了什么
- 看到了什么
- 听到了什么
- 与谁对话
- 玩家说过什么
- 玩家给了什么
- 玩家是否造成伤害
- 战斗中发生了什么

## 睡前总结

每天睡前，NPC 将短期记忆压缩为：

1. 知识图谱更新
2. 第一人称日记

然后清空当天短期记忆缓存。

## 记忆注入原则

每次 LLM 调用不要注入所有历史，只注入：

- NPC 人设核心
- 当前状态
- 当天短期记忆摘要
- 与当前对话对象相关的知识图谱条目
- 与当前地点相关的知识图谱条目
- 日记
- 与玩家相关的高重要性记忆
