# Quaternius Runtime Selection

本目录只接收从 Quaternius 官方包中筛选并完成许可登记的运行时资产。T0125–T0128 保留 10 GLB / 31 PNG；T0129–A3b11R 逐步加入铁匠铺、诊所、食堂、酒窖、菜园、训练场、教堂、工械坊与主厅素材。A3b12R 新增 `warehouse_wall_woodgrid / roof_wooden / wagon / shelf_arch / bag / metal_crate / apple_barrel / chest` 八个 GLB，全部复用既有外置纹理。T0135-P1 又从 Stylized Nature MegaKit 筛入 `nature/ground_detail/` 下 5 个地表细节 GLB 和 3 张共享纹理，用于无碰撞卵石、短草与三叶草；P2 复用其中两种卵石，以放大、非均匀缩放和灰褐覆写形成无碰撞岸坡岩石轮廓，没有重复导入源模型。`Workbench_Drawers` 因网格质量未进入本目录；完整源包、拒收候选、重复格式和未筛选资产继续留在 `art_source/`。新增资产必须通过对应美术验证并更新第三方台账。
